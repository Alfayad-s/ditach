# @detach/backend

NestJS REST API for the DETACH clothing brand platform.

Run from the repository root:

```bash
pnpm dev:backend
```

- API: http://localhost:4000/api/v1
- Health: http://localhost:4000/api/v1/health
- Swagger: http://localhost:4000/api/docs

Copy `apps/backend/.env.example` to `apps/backend/.env` before running.
